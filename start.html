How it works

From a crumpled slip to a clear picture.

01 — SNAP IT

Faded, crumpled, sideways. Still readable.

Tally straightens the photo, looks closer where the print is faint, and reads it on the phone itself. Nothing is uploaded. No receipt? Just type an amount.

02 — CHECK IT

Tally shows its working.

It reads every line, including discounts, SST, service charge and 5-sen rounding, then checks the items add up to the total. If a line looks off, Tally points at it so you can fix it. Fix one, and it remembers next time.

03 — FILE IT

One trip, sorted by item.

One hypermarket run can be food, medicine and cleaning. Tally puts each item in its own category, so your budget shows what you really bought. Correct one, and it remembers next time.

04 — RELIEFS

Tax season, without the shoebox of receipts.

As you log, Tally flags receipts and items that may count as LHDN relief candidates, like books, a gym, a medical check-up or kindergarten fees, and keeps each receipt photo beside them. Shown against this year’s usual limits.

FAQ

Fair questions.

Still unsure? Tally is open source, so you can read the code on GitHub.

Is it really free?

Yes. Every feature is free, with no premium tier and no ads. It’s a passion project, and because your phone does the work there are no servers to pay for.

Where does my data go?

It stays on your phone. There’s no account. Receipts are read on the device and never uploaded. If you back up, it goes to your own Google Drive or a file, only when you choose.

Will it read my receipts?

It copes with faded, crumpled, far-away and sideways photos, and recognises about 2,900 Malaysian chains and shop names. It won’t be right every time, which is why it checks the items add up to the total and points at any line worth a second look. Fix one and Tally remembers it next time.

Is it a real app if I install it from a browser?

It’s a web app that installs to your home screen, opens like an app and works offline once opened. A Play Store version is coming.

What if I change phones?

In Settings, Backup & restore makes a backup file. Send it to yourself (Google Drive, email, WhatsApp), then restore it on the new phone. There’s no account, so back up before you switch.

Can I bring my old data?

Yes, from Money Manager, Cashew, Money Lover, Spendee, Wallet and others, and from bank-statement files. Your old categories come along.

Is the tax relief part tax advice?

No. Tally flags receipts and items that may count as relief candidates, with this year’s usual limits. It’s an estimate to help you prepare. Please check LHDN’s rules for what you can claim.

Who makes it?

One independent developer in Malaysia. It’s open source (MIT), so you can read the code on GitHub. Feedback or a bug? Open an issue on GitHub.

What if I stop using it, or it stops being updated?

Your data is on your phone, and you can make a backup file whenever you like. The code is open source (MIT) on GitHub, so it isn’t locked away.
